Time zone boundaries

Open data used by Luach Or · published under the ODbL

Luach Or works out which clock a coordinate belongs to using a small database derived from OpenStreetMap. The ODbL asks that the derived database be offered to anyone who receives the app. This page is that offer — everything is below, and you may take it and use it under the same license.

Download the data

The database, in machine-readable form:

  • tz-patch.json — the database itself, 35 KB.
  • tz-patch.ts — the same data with a small lookup function, which is the form the app uses.
  • gen-tz-patch.mjs — the generator, so you can rebuild it from the source yourself rather than trusting this copy.

Each is served straight from this page’s own address, so the offer resolves wherever this page does.

What it is

A grid that answers one question: given a latitude and longitude, which time zone is it in? Every figure below is read from the file itself.

  • Window — latitude 29.0 to 33.5, longitude 34.0 to 36.0. Israel and its immediate neighbors.
  • Grid — 1800 × 800, which is 1,440,000 cells.
  • Resolution — 0.0025°. A cell is about 278 m of latitude, so a border is placed to within roughly 139 m.
  • Zones — Africa/Cairo, Asia/Riyadh, Asia/Amman, Asia/Jerusalem, Asia/Gaza, Asia/Hebron, Etc/GMT-2, Asia/Damascus, Asia/Beirut.
  • Size — 35,532 bytes as JSON.

Why it exists

General-purpose packed time zone rasters have little resolution in the Gulf of Aqaba corner, and hand Asia/Amman to everything below about latitude 30. That includes Eilat, Yotvata, Ketura, Samar and Ovda.

It matters because Jordan stopped observing daylight saving in 2022 and Israel did not. An app using the coarse data would have told someone in Eilat to light Shabbat candles at 17:44 when the correct time is 16:44 — forty minutes after sunset. This grid is the fix, and no border in it was drawn by hand.

Where it came from

Extracted from timezone-boundary-builder, whose boundaries are built from OpenStreetMap and whose own README licenses its output under the ODbL.

The npm package that packs that data declares CC0, and that declaration covers its code. The boundaries themselves remain OpenStreetMap’s and remain under the ODbL, which is why this page exists.

The app

Luach Or is a Jewish calendar, zmanim and blessings reference for iPhone. It uses this data to know which clock your city keeps.
